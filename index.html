개요

Copilot Studio란?

Microsoft Copilot Studio는 기업과 개발자가 AI 에이전트(Agent)를 쉽고 빠르게 만들 수 있도록 설계된 로우코드 플랫폼입니다.

🤖

AI 에이전트 빌더

자연어로 에이전트를 설명하면 AI가 자동으로 토픽(Topic)과 대화 흐름을 생성해 줍니다. 기술적 배경 없이도 누구나 에이전트를 제작할 수 있습니다.

🔗

Power Platform 통합

Power Automate, Power Apps, Dataverse와 완벽하게 통합되어 기업의 기존 데이터와 자동화 흐름을 에이전트에 연결할 수 있습니다.

🛡️

엔터프라이즈 보안

에이전트는 사용자의 권한 범위 내의 데이터만 접근합니다. Microsoft 365의 보안 정책과 Entra ID 인증을 그대로 활용합니다.

🌐

두 가지 에이전트 유형

커스텀 에이전트: 독립형, Teams·웹·M365 등 다양한 채널에 배포 가능
선언형 에이전트: Microsoft 365 Copilot을 특정 업무에 맞게 확장

핵심 기능

4가지 핵심 구성 요소

Copilot Studio 에이전트는 Knowledge, Tools, Topics, Agents 네 가지 핵심 구성 요소로 이루어집니다.

01
📚

Knowledge (지식 소스)

SharePoint, OneDrive, 공개 웹사이트, Dataverse 등 조직의 데이터 소스를 에이전트에 연결합니다. 에이전트는 설정된 지식 소스에서 정보를 검색하고 생성형 AI로 답변을 생성합니다. FAQ를 일일이 만들 필요 없이 문서를 연결하는 것만으로 지식 기반 에이전트를 구축할 수 있습니다.

SharePointOneDriveWeb SearchDataverse
02
🔧

Tools (도구)

에이전트가 실제 작업을 수행할 수 있도록 외부 서비스와 연결합니다. MCP(Model Context Protocol) 서버, 커스텀 커넥터, Power Automate 흐름 등을 통해 계정 조회, 데이터 업데이트, 외부 API 호출 등의 작업을 자동화할 수 있습니다.

MCP 서버Power Automate커스텀 커넥터REST API
03
💬

Topics (토픽)

에이전트가 사용자와 대화하는 방식을 설계합니다. 트리거 문구(Trigger Phrase)와 대화 경로(Conversation Path)를 정의하고, 분기(Branch) 처리, 변수(Variable) 활용, 시스템 토픽 설정이 가능합니다. 로우코드 캔버스에서 시각적으로 비즈니스 로직을 구성할 수 있습니다.

트리거 문구대화 경로분기 처리시스템 토픽
04
🤝

Agents (에이전트 연결)

여러 에이전트를 서로 연결하여 복잡한 업무를 효율적으로 분담시킬 수 있습니다. 특정 업무 영역을 전담하는 에이전트를 만들고, 조직 내 다른 에이전트와 협력하도록 구성하여 솔루션을 확장할 수 있습니다.

멀티 에이전트에이전트 오케스트레이션확장성
AI 기능

강력한 AI 기능

Copilot Studio는 생성형 AI를 활용하여 에이전트 제작과 운영을 한층 더 지능적으로 만듭니다.

✨

생성형 답변 (Generative Answers)

지식 소스(SharePoint, OneDrive, 웹사이트 등)를 연결하면 에이전트가 동적으로 정보를 검색하고 AI가 자연스러운 답변을 생성합니다. 출처 인용도 자동으로 포함됩니다.

🏗️

생성형 빌더 (Generative Builder)

자연어로 원하는 에이전트를 설명하면 AI가 토픽과 대화 흐름을 자동으로 설계해 줍니다. Adaptive Card 생성도 지원하여 비기술 사용자도 빠르게 에이전트를 구축할 수 있습니다.

🖥️

컴퓨터 사용 (Computer Use)

API 없이도 에이전트가 화면을 시각적으로 분석하고 단계별로 작업을 수행합니다. 레거시 애플리케이션이나 API가 없는 데스크톱 워크플로우도 자동화할 수 있습니다.

배포 채널

다양한 채널에 배포

Copilot Studio 에이전트는 한 번 만들면 여러 채널에 동시에 배포할 수 있습니다.

💼

Microsoft Teams

팀 업무 채팅 환경에서 바로 에이전트와 대화할 수 있습니다.

🌐

웹 채팅

조직 내부 포털이나 외부 웹사이트에 에이전트를 임베드할 수 있습니다.

🤖

Microsoft 365 Copilot

Microsoft 365 Copilot에서 선언형 에이전트로 직접 실행됩니다.

📱

모바일 & 기타

Slack, Facebook, LINE 등 다양한 외부 채널로도 확장 배포가 가능합니다.

시작하기

Copilot Studio 시작 방법

아래 단계를 따라 첫 번째 AI 에이전트를 만들어보세요.

Step 1

포털 접속

copilotstudio.microsoft.com에 Microsoft 365 계정으로 로그인합니다.

Step 2

에이전트 생성

「새 에이전트 만들기」를 클릭하고, 원하는 에이전트를 자연어로 설명하면 생성형 빌더가 초안을 만들어줍니다.

Step 3

지식 & 도구 추가

SharePoint, OneDrive 등의 지식 소스와 Power Automate 흐름, 커넥터를 연결합니다.

Step 4

테스트 & 배포

내장된 테스트 창에서 에이전트를 테스트한 후, Teams, 웹 등 원하는 채널에 게시합니다.

지금 바로 시작해보세요!
